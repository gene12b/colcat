= colcat

Colored-concatenate (colcat) is essentially a natural-language language server protocol (LSP). The goal of colcat
is to provide visual cues that can make reading human languages easier by (at the base level) modifying the 
text coloring and (in more capable text viewers) modifying the font style, background color, size, orientation, and
other such percievable visual properties. The underlying concept is to improve the _saliency_ of the text, which
currently is modelled in the human visual system as a combination of visual properties _intensity_, 
_orientation_, and _color-opponency_. _intensity_ is how bright or dark something is, _orientation_ is how sharp changes
in direction lines are (simplifies font shape), and _color-opponency_ is the maximum color difference between a letter
and its background (red-green and yellow-blue are opposite colors and therefore max color-opponency).
This is something that is already done in a rudimentary capacity through
highlighting text, making it bold, changing text color, making it all-caps, italicizing, and a variety of other
text-styling techniques. By having a common color-pallete, it is possible to associate color with text and 
more easily identify words of interest.

This app was inspired by `bat`.

== Usage

`cargo install colcat`

if you want be able to use a sentence-transformer's model such as all-MiniLM-L6-v2 (https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2) 
in order to score and accordingly color sentences based on semantic similarity to a target phrase you provide use

`cargo install colcat --features=semantics`

All colors used are CSS colors, so when you're defining config colors they should be CSS parsable color text.

If you add `--release` in addition you'le get a performance boost in addition to 

`--generate-config-schema <.json Path>` will create a json schema listing all the possible types and
values you need in order to completely customize the config.json you pass to colcat.
